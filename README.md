A one-image summary of the world news of **Monday, 23 November 2026** — a
newspaper-style front page ("THE WORLD IN ONE DAY") with six stories that
defined the day: Ukraine sinking the Russian corvette Merkury off Libya, the
KOSPI's 3.3% slide as the AI rout deepened, the blame game after the COP31
collapse, FIFA confirming the UK as hosts of the 2035 Women's World Cup,
Belgium's airports shut by a national strike, and Russian strikes killing
11 near Kyiv.

The image is original procedural artwork: drawn programmatically with Pillow
(see `render.py`, Liberation Sans), no photos or copied artwork. The program
itself is a Node 22 standard-library script that copies `entry.png` to the
output directory, so repeated runs produce byte-identical output.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
